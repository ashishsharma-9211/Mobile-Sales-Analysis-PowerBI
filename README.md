# 📱 Mobile Sales Analysis Dashboard | Power BI

An interactive Power BI dashboard designed to analyze mobile sales performance, customer behavior, product trends, and payment preferences.

## 📊 Dashboard Preview

![Mobile Sales Dashboard](Screenshot%202026-11-07%20174523.png)

## 🎯 Project Objectives

- Analyze overall mobile sales performance.
- Track monthly sales and quantity trends.
- Identify top-performing mobile brands and models.
- Understand customer ratings and purchasing patterns.
- Analyze city-wise sales distribution.
- Compare different payment methods.
- Explore day-wise sales performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Excel
- Data Visualization

## 📈 Key Performance Indicators

- Total Sales
- Total Quantity
- Total Transactions
- Average Sales

## 🔍 Dashboard Features

- Interactive monthly filters.
- Brand and mobile model analysis.
- Payment method analysis.
- Customer rating distribution.
- Geographical sales visualization.
- Dynamic cross-filtering across visuals.

## 🚀 How to Run

1. Download this repository.
2. Open `dashboard_project_1_done.pbix` in Power BI Desktop.
3. If prompted, update the Excel data source path.
4. Refresh the dataset.
5. Explore the dashboard using interactive filters.
